# Product Hunt launch checklist

## Timing
- Day: Tuesday, week 2 or 3 of the month
- Time: 12:01 AM PT (Pacific midnight)
- Avoid weeks OpenAI or Anthropic announce

## Hunter
- First choice: Chris Messina (top hunter, AI-friendly)
- Backup: Kevin William David
- Or any AI-tool-focused hunter with a track record

## Required assets

### Tagline (under 60 chars)
"The agentic desktop for builders. Local + cloud, one runner."

### Description (under 260 chars)
"Brocco runs multiple Claude / GPT / local LLM agents in parallel from one prompt. BYOK, browser-first, install as a desktop app. Free tier: 100 runs/mo. Built for solo founders who want agents that ship work, not summaries."

### Hero gif (autoplay, under 3 MB, 1270x760 ideal)
Suggestion: 12-second screencast of /app/ showing
1. User clicks Broadcast mode
2. Selects 3 agents (researcher, outreach, coder)
3. Types "Plan a launch for my SaaS"
4. Hits Run, 3 panes spawn, each visibly working
5. Pans across the cost meter ticking up

### Screenshots (4 minimum, 1270x760)
1. Empty dashboard with library + recipe cards
2. Single agent running with tool-call stream visible
3. Broadcast mode with 3 panes filled
4. BYOK modal with the trust copy ("stays in your browser only")

### Demo video (under 60s, 1080p)
Voiceover-free is fine. Caption overlay every 4-5s.

## Day-of cadence

- 12:05 AM PT: Pinned tweet from @brockpivec with PH link
- 12:10 AM PT: Email blast to free-tier users
- 12:30 AM PT: Post in 6 communities (Discord, Slack)
  - Latent Space Discord: #show-and-tell channel
  - Buildspace n&w: weekly thread
  - Cursor Community: build channel
  - r/SideProject: link post
  - r/AI_Agents: link post
  - Indie Hackers: launch post
- Reply to every PH comment within 5 minutes for first 8 hours
- Re-share at 8 AM, noon, 5 PM PT in different framings

## Seeding
- 48 hours BEFORE: drip-message to ~150 warm contacts (Discord, X, customers)
- Polite ask, no pressure
- NEVER buy upvotes, PH detects this and shadowbans

## Goal
Top 3 of day = ~5,000 visits + newsletter pickup. Top 1 = ~15,000.

## Post-launch
- Day after: tweet "thanks" thread with stats (visits, signups, badges)
- Week after: write the launch retro on the blog
- Month after: pitch TechCrunch / The Information with the numbers
