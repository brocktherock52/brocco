Bring your own key

Brocco runs in your browser. Your Anthropic key is stored in localStorage on this device only, never sent to brocco servers, never logged. All agent calls go directly from this tab to api.anthropic.com.

Don't have a key? Get one from Anthropic. Pricing is pay-as-you-go: roughly $0.003 per agent run on Sonnet.
