MCP server setup (Claude Desktop, Cursor)

The brocco MCP server exposes every brocco agent as a callable tool inside Claude Desktop or any MCP-compatible client. Each agent (researcher, coder, outreach, supervisor, etc.) becomes a tool you can call from a Claude conversation.

Step 1, install Charter (the brocco runtime, ~64 KB Python package):

git clone https://github.com/brocco-ai/charter
cd charter
pip install -e .

Step 2, edit claude_desktop_config.json (find it via Claude Desktop » Settings » Developer » Edit Config):

{
  "mcpServers": {
    "brocco": {
      "command": "python",
      "args": ["-m", "charter.mcp_server"],
      "env": {
        "ANTHROPIC_API_KEY": "sk-ant-...",
        "TAVILY_API_KEY": "tvly-..."
      }
    }
  }
}

Step 3, restart Claude Desktop. Open a new chat. The brocco tools appear under the ↓ tools menu in the input box.

REST API for ChatGPT, n8n, curl

The same agents are available over HTTP. Pass your own Anthropic key as a Bearer token (BYOK pass-through) or use a brocco API key from /account.

curl -N https://brocco-site.vercel.app/api/v1/run \
  -H "Authorization: Bearer sk-ant-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{"agent": "researcher", "prompt": "Top 3 alternatives to Notion under $20/mo"}'

Response is a Server-Sent Event stream of JSON events: run_started, step_start, tool_call, tool_result, assistant_turn, assistant_text, run_finished. List available agents at GET /api/v1/agents.
