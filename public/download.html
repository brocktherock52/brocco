MCP server setup (Claude Desktop)

The brocco MCP server exposes every brocco agent (researcher, coder, outreach, supervisor, etc.) as a callable tool inside Claude Desktop. Once configured, you can write "use the brocco_researcher tool to find me 5 alternatives to Notion" in any Claude conversation and it runs the real agent.

Step 1, install Charter (the brocco runtime):

git clone https://github.com/brocco-ai/charter
cd charter
pip install -e .

Step 2, add to claude_desktop_config.json (find it via Claude Desktop » Settings » Developer » Edit Config):

{
  "mcpServers": {
    "brocco": {
      "command": "python",
      "args": ["-m", "charter.mcp_server"],
      "env": {
        "ANTHROPIC_API_KEY": "sk-ant-...",
        "TAVILY_API_KEY": "tvly-..."
      }
    }
  }
}

Step 3, restart Claude Desktop. Open a new chat. You should see the brocco tools appear under the ↓ tools menu in the input box. Test:

You: use brocco_researcher to find the top 3 AI dev tools shipped this week.

Claude: [calls brocco_researcher with prompt] ... [brocco runs, returns sourced brief]

REST API for ChatGPT / curl / anything

The same agents are available over HTTP at https://brocco-site.vercel.app/api/v1/run. Pass your own Anthropic key as a Bearer token (BYOK) or use a brocco API key from /account.

curl -N https://brocco-site.vercel.app/api/v1/run \
  -H "Authorization: Bearer sk-ant-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{"agent": "researcher", "prompt": "Top 3 alternatives to Notion under $20/mo"}'

Response is a Server-Sent Event stream of JSON events: run_started, step_start, tool_call, tool_result, assistant_turn, assistant_text, run_finished. List available agents at GET /api/v1/agents.

Why three install paths

PWA is the right choice for 95% of users. One click, works everywhere, auto-updates, no separate binary to trust. Native (Tauri) is for the 5% who want a real Dock icon and code-signed binary they can hand to IT. MCP is for power users who already live inside Claude Desktop or Cursor and want brocco's agents available as tools without leaving that surface.

All three hit the same Charter runtime under the hood, the same agents, the same prompts.
