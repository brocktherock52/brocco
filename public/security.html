Data handling

Brocco stores three categories of data:

  • Account data.email, billing, SSO subject. Stored in Postgres with row-level encryption.
  • Agent specs & tool definitions, your prompts and tool code. Stored in Postgres + S3-compatible object storage.
  • Run logs.every prompt, tool call, and result, written as JSONL. Retained for 90 days by default; you can shorten or extend in dashboard settings, or set a per-agent retention.

We do not store credentials passed through tool calls (e.g. API keys you set on a custom HTTP tool); those are referenced from your secret store at run time.

Models & training

Brocco runs on Anthropic's API.Claude Opus 4.7, Sonnet 4.6, and Haiku 4.5. We send requests with x-anthropic-no-data-retention set, meaning Anthropic retains nothing after the response is returned.

We do not use your data to train, fine-tune, or evaluate any model.ours, Anthropic's, or anyone else's. This is contractual and enforced by our deployment configuration.

Access controls

  • SSO/SCIM.Okta, Google Workspace, Azure AD on Team and Enterprise.
  • RBAC.admin / operator / viewer roles, scoped per agent.
  • Audit logs.every agent run, spec edit, and tool call recorded. Exportable as JSONL.
  • BYOK.supply your own Anthropic API key on Team and above; we never see it in plaintext.

Infrastructure

Multi-region (us-east, eu-west) on Vercel for the control plane and Hetzner for long-running agent workers. Postgres on Neon. Object storage on Cloudflare R2. All inter-service traffic is mTLS. Background workers run in isolated containers; tool definitions execute in a sandboxed Python subprocess with no network access except via the registered HTTP tool.

Incident response

P0 incidents: notification within 24 hours via email and dashboard banner. Post-mortem published within 7 days. Status page at status.brocco.ai (live once SOC 2 audit closes). Security disclosures: security@brocco.ai.PGP key on the page footer.

Deletion & portability

Delete your account from Settings → Account → Delete. Within 24 hours we purge: account record, agent specs, tool definitions, run logs, persistent memory. Immutable backups are aged out within 30 days. Export your full dataset as a single ZIP from Settings → Export at any time.JSONL run logs, agent markdown, memory JSON, billing history.

Contact security

Vulnerability reports: security@brocco.ai. We acknowledge within one business day, triage within three, and reward verified findings on a hall-of-fame + bounty basis. Pen-test reports available under NDA.request via the same address.
