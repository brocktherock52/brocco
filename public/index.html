01 / CONNECT

Wire up your stack

Stripe, Gmail, Notion, Slack, Shopify, Postgres, custom HTTP. Drop a tool definition, the agent gets superpowers. Every connection is an embedded workflow.

02 / DESCRIBE

Write the agent in markdown

A few lines of prose plus a tool list. No code. The agent decomposes your goal, picks the right tool, runs it, reads the result, decides what's next.

03 / RUN

Trigger or schedule, walk away

Webhook, cron, or chat. Every step is logged as JSONL. Human-overrideable, audit-grade, persistent across restarts. Real work, on autopilot.

Features

Production-grade. Audit-ready. Yours.

⌬

Multi-agent orchestration

Supervisor pattern with sub-agent delegation. Specialists for research, code, outreach, ops.each with its own tool set and memory.

⊟

Tool registry

File, shell, HTTP, search, your custom APIs. Each tool is a Python factory.type signature in, the agent gets it on next run.

≡

Full audit trails

Every prompt, tool call, and result is appended to JSONL. Replay any run. Diff two runs. Compliance-ready by default.

◐

Persistent memory

Per-agent KV that survives across runs. The agent remembers what it learned yesterday, today.

↯

Prompt caching, on by default

System prompts and tool definitions cached on Anthropic's edge. Cuts cost ~80% on repeated workflows. No flag to flip.

⌂

Self-host or hosted

Run on Hetzner, Vercel, your laptop. SOC 2 Type II in progress. BYOK. Encrypted at rest. Your data never trains a model.
