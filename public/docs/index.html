Quickstart

Your first agent in 11 minutes.

Install the runtime, drop a markdown spec, run a tool-using agent against your business. No build step, no framework lock-in.

On this page

1. Install 2. Configure 3. First agent 4. Run it 5. Add a custom tool 6. Deploy 24/7 Next steps

1Install

Brocco's runtime is Charter, a 64KB Python package. Python 3.11+:

# clone or pip install
git clone https://github.com/brocco-ai/charter
cd charter
pip install -e .

2Configure

Set your Anthropic API key (and Tavily for web search) in .env:

ANTHROPIC_API_KEY=sk-ant-...
TAVILY_API_KEY=tvly-...
CHARTER_DEFAULT_MODEL=claude-sonnet-4-6
BYOK note: on Team and Enterprise, Brocco never sees your key in plaintext, your key talks to Anthropic directly from your runtime.

3Write your first agent

Create agents/my_agent.md. Frontmatter is YAML; the body is the system prompt.

---
name: lead_qualifier
model: claude-sonnet-4-6
max_tokens: 4096
tools: [search_web, http_get, memory_put, file_write]
description: Research a lead and draft a personalized opener.
---

You research one inbound lead and draft a custom opener.

Workflow:
1. Search the web for the company name + role
2. Fetch the most informative URL
3. Save 3 facts about them to memory
4. Write a 3-line opener to opener.md.no fluff,
   open with a fact about them.

4Run it

python -m charter run lead_qualifier "Lead: Sarah Chen, AE at Vercel, sarah@vercel.com"

You'll see the agent stream every step: step_start → tool_call → tool_result → assistant text → run_finished. Every event is appended to data/runs/<id>.jsonl so you can replay or audit later.

5Add a custom tool

Drop a Python file under charter/tools/ and register a factory. The agent gets your tool on the next run.

# charter/tools/stripe_lookup.py
from charter.tools.registry import ToolContext, register

def _factory(ctx: ToolContext):
    def stripe_customer_lookup(email: str) -> dict:
        import stripe, os
        stripe.api_key = os.environ["STRIPE_API_KEY"]
        c = stripe.Customer.search(query=f'email:"{email}"').data[0]
        return {"id": c.id, "name": c.name, "created": c.created}
    return ({
        "name": "stripe_customer_lookup",
        "description": "Look up a Stripe customer by email.",
        "input_schema": {"type": "object",
            "properties": {"email": {"type": "string"}},
            "required": ["email"]},
    }, stripe_customer_lookup)

register("stripe_customer_lookup", _factory)

Add stripe_customer_lookup to any agent's tools: frontmatter list and you're done. Charter's registry is import-time; just touching the file is enough.

6Deploy 24/7

Three paths:
